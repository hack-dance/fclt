# Instruction authority and generated defaults

Generated work-unit, specialist, review, and provider guidance should preserve the same authority
boundary: complete authorized work without repeating approval for the same scope, keep read-only work
read-only, and prepare a concrete result before any remaining external-action or destructive-change
gate. Required checks remain mandatory; repeated testing needs new evidence or an unresolved risk.

The operating-model pack is generic. Personal framework, model, account, and publishing preferences
belong in user-owned canonical assets. Codex automation scaffolding uses the configured default model
and reasoning effort, including an explicitly selected profile. Without a configured selection, the
existing template fallback remains for compatibility; it is not a claim about the newest model.
Existing automation files are preserved unless replacement is explicitly requested.

Writebacks capture reusable evidence. Authorized drafts do not imply canonical apply, promotion,
external tracker writes, or scheduler activation. Scheduled reviews keep unchanged results quiet and
must verify the producing workflow before resolving writebacks as improved.

Broad managed sync remains deprecated and contained. Preview the exact target set; do not enable
legacy mutation merely to deploy a single instruction. Provider settings, credentials, unrelated
skills, and native content must survive any deployment. Source updates and provider readback are
separate from fresh-session discovery and observed behavioral effectiveness.

The [Astra prompting guide](https://developers.openai.com/api/docs/guides/latest-model#prompting-best-practices)
informed these changes. The rules remain provider-neutral and subject to each runtime's actual
capabilities, safety rules, and explicit operator authorization.

Claude specialist agents render to Markdown under `~/.claude/agents` or `.claude/agents`,
with a name, description, and `model: inherit`. Rendering does not set permission modes or copy an
OpenAI model selection into Claude. See the [Claude subagent format](https://code.claude.com/docs/en/sub-agents).
